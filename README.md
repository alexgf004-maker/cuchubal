# Cuchubal

Ruleta para sortear los turnos de un cuchubal.

1. Escribe el nombre del grupo y elige el mes de inicio.
2. Anota a los participantes, uno por línea.
3. Activa los montos si quieres ver cuánto recibe cada turno.
4. Gira la ruleta y comparte el resultado por WhatsApp.

El sorteo se hace en el navegador con el método Fisher‑Yates y números aleatorios seguros. Los nombres y resultados no se envían a ningún servidor.
